# 语文学科高频任务分析项目

## 项目概述

本项目对2025年秋季学期（2025年9月-2026年1月）的语文学科"其他"类型任务进行高频分析，旨在识别高频且耗时较长的任务类型，为AI提效方案提供数据支持。

## 数据范围

- **时间范围**: 2025年9月 - 2026年1月
- **学期**: 2025年秋季学期
- **任务类型**: 学校作业（任务类型二级为"其他"）
- **学科**: 语文
- **数据量**: 30,853条任务记录（已剔除年级未知数据）
- **覆盖地区**: 福州、广州、西安
- **覆盖年级**: 小学一至六年级

## 核心发现

### TOP 5 高频任务

1. **其他** (未细分类别): 10,359次 (33.58%), 平均22.4分钟
2. **预习**: 3,241次 (10.50%), 平均20.6分钟  
3. **阅读**: 2,741次 (8.88%), 平均24.0分钟
4. **练字/字帖**: 2,105次 (6.82%), 平均20.7分钟
5. **订正**: 2,011次 (6.52%), 平均20.1分钟

### 高频且耗时较长的任务（重点关注）

**筛选条件**: 任务数量 ≥ 500 且 平均时长 ≥ 20分钟

这些任务具有【高频次】+【耗时长】的特点，是AI提效的重点目标：

### 年级特征

- **低年级（1-2年级）**: 以拼音、识字/生字、练字为主
- **中年级（3-4年级）**: 订正、默写/听写、阅读任务增加
- **高年级（5-6年级）**: 复习、作文、小练笔比重提升

## 项目文件说明

### 数据文件
- `任务明细-语文其他.xlsx` - 原始数据文件

### 分析脚本
- `analyze_tasks.py` - 初步数据探索脚本
- `task_frequency_analysis.py` - 第一版分析脚本
- `task_frequency_analysis_v2.py` - 优化版分析脚本（推荐使用）
- `generate_report.py` - 报告和图表生成脚本

### 输出结果

#### 主要报告
- `高频任务分析报告.txt` - 完整的文字分析报告
- `高频任务分析图表.png` - 6个维度的可视化图表
- `高频任务分析汇总.xlsx` - Excel汇总表（包含多个工作表）

#### 详细数据
- `高频任务统计_优化版.xlsx` - 所有任务类型的详细统计
- `任务类型样本描述_优化版.xlsx` - 各类任务的样本描述（每类TOP50）
- `分年级任务分布_优化版.xlsx` - 各年级的任务分布情况
- `未分类任务详情.xlsx` - 仍未能自动分类的任务详情
